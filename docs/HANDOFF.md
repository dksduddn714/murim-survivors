# 개발 인수인계

## 합의한 방향
귀여운 도트 무협의 뱀서류, 모바일 가로 화면. 정파·사파·마교에 따라 다른 두 세력이 적으로 등장. 브라우저 출시 후 앱 출시 목표. ChatGPT와 Claude가 GitHub에서 협업할 계획.

## 이번 배치
10개의 의미 있는 소스 변경을 별도 커밋으로 기록했습니다. CHANGELOG에 각 단계가 있습니다. 최종 결과를 한 번에 배포하므로, 10번의 스토어/웹 출시를 했다는 의미는 아닙니다.

## 개발 시 유의점
- 전투 루프는 경과 시간 기반 setInterval, 프레임당 dt는 최대 .1초. 탭이 숨겨지거나 포커스를 잃으면 일시정지합니다.
- 상태는 game.js의 `state`, 메뉴 상태는 `mode`에 있습니다. 현재 전역 스크립트 실행 순서를 index.html이 지정합니다.
- render()는 게임 상태를 그립니다. 후속 리팩터링 시 시뮬레이션과 렌더러를 분리하는 것이 좋습니다.
- 데이터 저장 스키마는 version:1. 스키마 변경 시 마이그레이션을 추가하세요.
- 무공은 인덱스 0~7: 검기, 비도, 호신검, 진각, 심법, 보법, 독무, 천뢰장.
- 보스의 final 여부로 최종 보스 처치와 중간 보스 처치를 구분합니다.
- GitHub 계정은 연결했으며 저장소 생성은 별도 단계입니다. Sites 소스 원격은 별개로 존재합니다. 이를 GitHub 저장소라고 부르지 마세요.

## 남은 검증
Android/iOS 실제 기기의 장시간 성능, 홈 화면 설치, 오프라인 재실행, 소리 활성화 정책, 블루투스 입력은 별도 검증이 필요합니다. Node 테스트는 실제 브라우저 렌더링을 대체하지 않습니다.

## 검증 결과
- Node 검사 9개: 세력·지역별 2분 시뮬레이션, 5분 종료, 입력/정지, 독립 무공/절학, 돌진 방향/선분 충돌, 보스 구분, 보상 중복 방지/수련, 저장 검증, 에셋/문법.
- 데스크톱 브라우저에서 메뉴·수련·세력·지역 선택과 설산 사파 전투(시간 진행, 처치 수 증가)를 확인했습니다.

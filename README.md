# 무림혈전
가로형 모바일 도트 무협 생존 게임. 정적 HTML/CSS/Canvas JavaScript, 외부 게임 라이브러리 없음.

## 실행
`python -m http.server 8080 --directory dist`

## 현재 기능
- 정파/사파/마교 선택: 다른 두 세력이 적으로 등장, 기본 무공 차이
- 드래그/키보드 이동, 자동 공격, 경공, 내공 획득, 무공 선택과 강화
- 5분 생존, 4분 장로 등장. 제한 시간 내 장로 처치 후 생존해야 승리
- 일시정지, 재시작, 기기 내 최고 처치 기록

## 협업
`AGENTS.md`를 읽고 기능별 브랜치에서 수정. GitHub 원격 저장소는 아직 연결되지 않음.
아트는 Canvas로 직접 그린 임시 픽셀 스프라이트. 최종 에셋과 사운드는 후속 제작.

# 무림혈전 · v0.4

가로 화면으로 즐기는 귀여운 도트 무협 생존 게임. 모바일 브라우저로 먼저 개발하고, 향후 Android/iOS 출시에 맞춰 확장합니다.

## 실행과 검증

Node.js 20+ 사용. 게임 실행에는 npm 패키지 설치가 필요하지 않습니다.

```sh
npm run dev
# http://localhost:8080
npm test
```

`dist/` 전체를 정적 호스팅에 배포합니다. `index.html`을 파일 탐색기에서 직접 여는 대신 HTTP 서버를 사용하세요. 서비스워커는 HTTPS 또는 localhost에서만 작동합니다.

## 플레이

- 정파: 청운검기로 시작, 체력 +20 / 사파: 추혼비도, 이동속도 +12 / 마교: 혈월장(진각), 피해 +12%
- 선택한 세력의 다른 두 세력이 적으로 등장합니다.
- 드래그·WASD·방향키 이동, 오른쪽 경공·SPACE 회피, ESC 일시정지.
- 5분 동안 생존하고 최종 보스를 처치해야 승리합니다. 중간 보스는 1:50, 최종 보스는 4:00 등장합니다.
- 무공 8종, 각 5중까지 성장. 검기4+호신검2=만검귀종, 비도4+독무2=만천화우, 진각4+천뢰장2=혈뢰천강.
- 금창약 회복 +30, 내공 회수 아이템. 경공 재사용 2.8초, 무적 0.45초.
- 출도 종료 시 은전 지급. 수련에서 체력·공격력·흡수 범위를 각 5단계까지 강화합니다.
- 지역: 청죽림(기본), 설산고개(적 체력+15%), 홍월폐사(적 체력+25%).

## 저장·설정

`localStorage`의 `murim.profile.v1`에 기기별 전적·은전·수련·설정을 저장합니다. 기기 간 동기화와 클라우드 계정 기능은 없습니다. 브라우저 데이터 삭제 시 기록이 지워집니다. 저장소가 차단되면 메뉴에 저장 불가를 표시합니다. 효과음 기본값은 꺼짐이며, 설정에서 켤 수 있습니다. 화면 흔들림도 끌 수 있습니다.

## 설치·오프라인

홈 화면 추가를 지원하는 브라우저에서 앱처럼 실행할 수 있습니다. 첫 정상 접속과 서비스워커 설치를 완료한 뒤 게임 파일을 오프라인으로 이용하도록 구성했습니다. 비공개 호스팅의 로그인 경로·인앱 브라우저·기기 정책에 따라 설치나 오프라인 동작이 제한될 수 있습니다. PWA는 스토어 출시 앱과 다릅니다.

## 협업과 다음 단계

`AGENTS.md`, `CLAUDE.md`, `docs/HANDOFF.md`와 `CHANGELOG.md`를 먼저 읽으세요. GitHub 원격 연결 여부는 실제 저장소 상태로 확인해야 합니다. 현재 소스는 외부 게임 라이브러리가 없는 Canvas 프로토타입이며 Phaser/TypeScript로 전환하지 않았습니다.

아트는 직접 그린 Canvas 도트와 아이콘, 소리는 Web Audio 합성입니다. 지형 장식에는 충돌이 없습니다. 후속 목표는 기기별 QA, 캐릭터 전용 스프라이트, 난이도 조정, 모듈 단위 상태 분리, Capacitor 패키징과 스토어 요구사항 검토입니다.

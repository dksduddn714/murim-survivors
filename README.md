# 무림혈전 (Murim Survivors) · v1.0.0

귀여운 도트 그래픽의 모바일 가로형 무협 뱀서류 생존 웹게임입니다.
정파(소림사·무당파·화산파·개방), 사파(혈도객·독공술사·귀영살수·녹림도왕), 마교(천마신교·혈마전·귀마전·흑염전) **총 12종의 세부 문파·캐릭터** 중 하나를 선택해 출도하며, 선택한 세력에 따라 **세력 전용 12비급(총 36종 무공)**과 **세력 전용 6대 합벽절학(총 18종 5★+5★ 합체 오의)**, 그리고 각 캐릭터 고유의 기본공격과 상태이상 연쇄 폭발을 구사합니다.

## 주요 기능 (v1.0.0)
- **3대 세력 × 4대 세부 문파/캐릭터 (총 12종 플레이어블 캐릭터)**:
  - **정파 (正派)**:
    1. **소림사 (少林寺)**: 불가 무공과 금강불괴 (대표 무공: `나한권`, `금강불괴신공`, `대력금강장`, `항마곤법` — 피해 감소·금강 충격파·광역 기절)
    2. **무당파 (武當派)**: 태극과 유연한 도가 검술 (대표 무공: `태극검법`, `태극권`, `양의검법`, `무당제운종` — 태극 검기 회전·반격·범위 제어)
    3. **화산파 (華山派)**: 매화와 화려한 쾌검 (대표 무공: `매화검법`, `이십사수매화검법`, `자하신공` — 분홍 매화 검기·연속 참격·치명타)
    4. **개방 (丐幫)**: 호쾌한 장법과 타구봉술 (대표 무공: `항룡십팔장`, `타구봉법` — 황금 용 장풍·강력 넉백·연타)
  - **사파 (邪派)**:
    1. **혈도객 (血刀客)**: `혈도참`·`혈기폭발` (출혈 중첩 및 적 처치 시 연쇄 **혈기 폭발**)
    2. **독공술사 (毒功術士)**: `만독연무`·`오독검기`·`부골독폭`·`만독고충술` (독무 확산 및 중독된 적 처치 시 **연쇄 독폭발**)
    3. **귀영살수 (鬼影殺手)**: `귀영분신`·`암영비도`·`귀영순보` (그림자 분신 십자베기와 순간이동 암살)
    4. **녹림도왕 (綠林刀王)**: `녹림참마도`·`광풍선풍참` (거대한 참마도를 휘둘러 전방의 적을 쓸어버림)
  - **마교 (魔敎)**:
    1. **천마신교 (天魔神敎)**: `천마신공`·`천마군림보`·`천마검법` (거대한 마기 폭발과 압도적 광역 공격)
    2. **혈마전 (血魔殿)**: `혈마신공`·`혈영장`·`혈폭술` (처치 시 생명력 흡수·피의 폭발·광역 출혈)
    3. **귀마전 (鬼魔殿)**: `귀혼공`·`귀영보`·`만귀소환술` (원혼 소환·적 공포 도주·유령 폭발)
    4. **흑염전 (黑炎殿)**: `흑염마공`·`마염검법`·`흑염폭룡` (검은 화염 지속 피해 및 처치 시 **흑염 연쇄 폭발**)
- **세력별 완전 차별화된 36종 무공 & 18종 5★+5★ 합벽절학(合璧絕學)**:
  - 정파 6대 합벽: `태극양의검진`, `이십사수매화검법`, `금강항룡신장`, `소림항마나한진`, `천하무구불괴진`, `무당진무태극공`
  - 사파 6대 합벽: `혈영만단참`, `당문만천화우`, `혈독멸절진`, `만독구천신공`, `녹림패왕파천도`, `무영귀살섬`
  - 마교 6대 합벽: `천마만귀멸세검`, `흑염만귀야행`, `천마혈해군림`, `흑염귀룡파천`, `혈마흑염신검`, `무상혈마군림`
- **무협 적 계급·직군 8종**:
  - 화산 검수 / 사파 혈도낭인 / 천마 전투대, 무당 도사 / 녹림 장창병 / 혈마전 창병, 정파 신궁수 / 당문 암기수 / 귀마전 혈침수, 매화 검객 / 귀영 살수 / 귀마전 야행자객, 소림 금강승 / 녹림 중갑병 / 흑염전 마갑호법, 개방 타구대 / 녹림 거한 / 혈마전 마존전사, 무당 태극도사 / 독공 주술사 / 귀마전 광명좌사, 보스(정파 무림맹 장로 / 사파 녹림총채주 / 마교 광명우사·대장로).

## v1.1 떠돌이 상인
- 첫 40~60초에 플레이어 주변 무작위 위치에 출현. 이후 65~85초 간격, 45초간 머무릅니다.
- 75px 이내 접근해 거래 버튼 또는 E키. 상품 4개는 방문 동안 고정되며 1~4키로도 선택 가능합니다. 거래 중 전투 정지.
- 검기/비도 강화 장비, 세력 비급(최대 5성), 최대 체력과 회복 물약, 경험치 회수 부적에서 무작위 4개.
- 현재 레벨의 미사용 경험치 게이지 전부를 지불해 상인당 하나만 구매. 레벨·필요 경험치·기존 무공·바닥 경험치는 유지. XP 0이면 구매 불가.
- 구매하지 않고 떠날 수 있고, 거래 종료 후 0.65초 보호 시간.
- 플레이어 피격 시 조작 정지나 강제 넉백 없이 이동 가능. 적의 피격 반동과 별개입니다.
- 자석은 습득 당시 바닥에 있는 경험치에만 적용되며 캐릭터 쪽으로 날아옵니다.
- 자동 검사 21개. 실제 모바일 터치·시각 검증은 별도 필요.

## v1.2 유한 전장·미니맵
- 전장 2400×1600 (x ±1200, y ±800). 보행·경공은 경계 18px 안쪽까지, 적 증원과 상인은 전장 안쪽에 배치.
- 경계 밖은 어둡게 표시, 금색 경계선.
- 우측 상단 미니맵: 청록 플레이어, 붉은 적, 큰 붉은 점 보스, 노란 사각형 상인, 회색 상인 거래 완료. 보이는 화면 범위를 사각형으로 표시.
- 가로 휴대폰 작은 화면은 축소 표시. 미니맵은 터치 이동을 가로채지 않음.
